# EHSS 2026 Conference Website

Static, no-build conference website for:

**Empowering Humanities and Social Sciences: A Discourse on Nation Building and Sustainability**

Department of Humanities & Social Sciences, IIT Roorkee, in association with NPTEL, IIT Madras.

Conference dates: 9–10 October 2026.

## Run locally

Open `index.html` in a browser. For the smoothest PDF behaviour, use a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish for free

### GitHub Pages
1. Create a GitHub repository.
2. Upload everything in this folder.
3. In GitHub, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/root`.
5. Save. GitHub will provide a free `github.io` address.

No build process is required.
